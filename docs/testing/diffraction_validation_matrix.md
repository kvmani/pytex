# Diffraction Validation Matrix

This document is the authoritative validation ledger for PyTex diffraction-facing workflows.

## Status Keys

- `implemented`: automated coverage and validation notes exist for the current category
- `foundational`: the implementation exists and is scientifically structured, but the
  external-baseline surface is not yet complete
- `planned`: the category is accepted but not yet validated adequately
- `n/a`: not applicable to current PyTex scope, with explanation

| Child-zone-anchored composite geometry (TX4) | Consistency identity: anchoring on variant k's own view of a parent zone reproduces the parent-anchored pattern to 1e-13 mm on every sub-pattern, with identical hkl ordering, for k = 1..4. Worked example in the composite-diffraction gallery. |
| Measured-pattern solving (TX5) | Simulate-then-solve closure on fcc [001], [011], [111], [112] and [013]: every spot indexed, mean residual <1e-9 1/A, zone-axis family recovered, and every spot's index family matching the one it was simulated from. Cubic identities reproduced from the solver's own output: \|g_220\|/\|g_200\| = sqrt(2) exactly and the (200)-(220) angle exactly 45 deg. Hexagonal alpha-Ti solved with four-index labels | implemented | `solve_saed_pattern(...)` — classical ratio/angle indexing from a calibrated spot list; intensities are never used. Distinct from `index_saed_pattern`, which needs a calibrated `DiffractionGeometry`. Worked example in the composite-diffraction gallery. |
| Pattern-solving discrimination and failure modes | An fcc pattern is not solved as bcc (systematic absences differ); the true phase outranks a decoy when both are offered; an unexplainable pattern returns **no** solution and `best()` raises rather than guessing; 0.5 mm picking noise still recovers the pattern with a nonzero residual, while 25 mm degrades to partial or absent rather than to a confident wrong answer | implemented | `is_conclusive` requires a full indexing and no genuinely different competitor; symmetry-equivalent descriptions and the zone-sense pair are not counted as competitors. |
| Pattern calibration and the YAML contract | `\|g\| = r/(L*lambda)` for millimetres; pixels scale through `pixel_size_mm` first; `camera_length_mm` with `beam_energy_kev` reproduces the camera constant at the relativistic 200 kV wavelength; YAML round trip preserves every coordinate exactly and validates against `schemas/measured_saed_pattern.schema.json` | implemented | Calibration is validated at construction — an uncalibrated length fails immediately rather than at the first spot. A spot coinciding with the transmitted beam is rejected: the beam is the calibration centre, not a reflection. |
| Variant assignment from a solved pattern | A Burgers alpha pattern anchored on variant 3's own basal zone is assigned variant 3 at <1 deg, given the parent's crystal-to-pattern rotation. An off-zone variant pattern (seen from a *parent* zone axis, so its child zone is irrational) is only partly indexed — the stated limitation, pinned | implemented | `assign_transformation_variant(...)` compares the solved orientation with each variant's prediction `P V_k^T` under the child point group. |
| Interactive spot-picking state machine | Add, remove-nearest with an optional radius, undo, clear, and centre-setting all behave; a picked session round-trips through YAML and solves to a full indexing; non-finite picks are rejected | implemented | `SpotPickerState` carries the logic with no Matplotlib dependency, so it is exercised headlessly; `SAEDSpotPicker` is a thin event adapter over it. |
| Kinematic spot-order stability | The same zone axis reached exactly and via a 1e-15 perturbation gives identical row order; repeated simulation is bitwise stable | implemented | Sort keys are quantized (1 pm of detector radius, 1e-12 of full-scale intensity) before `lexsort`, so symmetry-equivalent reflections fall through to the exact hkl tie-break instead of being ordered by floating-point noise. This was a real defect: the two anchoring routes previously produced correctly-positioned but permuted spot tables. |
| Double diffraction in kinematic zone-axis patterns | Silicon [110]: the structure-factor-forbidden 002 is absent by default and present when the option is enabled, flagged, with a {111}-type parent pair summing to it and an amplitude of zero. Centring closure: no I- or F-centring absence is ever revived, because a centring sublattice is closed under addition. Added intensity scales linearly with the coupling constant, and every added spot is weaker than every genuine one | implemented | `KinematicSimulationConfig(include_double_diffraction=True)` adds reflections reachable as the integer sum of two excited reflections, per `pytex.diffraction.kinematic.double_diffraction_sums`. The selection rule is exact and independent of the dynamical theory; the *intensity* (`coupling * sum over paths of I1 * I2`) is an observability estimate, and is declared as such in `SpotTable.describe()`, in the reflection table's `double_diffraction_origin` column, and by a hollow marker in the rendered pattern. Off by default. |
| Composite SAED manifest and file export | Manifest validates against `schemas/composite_saed_manifest.schema.json`; its file inventory equals the set of files actually written; parent + per-variant reflection counts sum to the pattern's total; every variant's exact and nearest-rational child zone axis round-trips from the pattern | implemented | `export_composite_saed(...)` writes table, figure(s), coincidence table and manifest; rendering leaves no open matplotlib figures (asserted). |
| Lattice-centering audit | A phase declaring `Im-3m` reports centering `I` as *declared*; a phase with no space group reports `P` as *assumed* and triggers an explicit warning in `describe()` and the reflection table; disabling absences is stated explicitly. Body centring forbids h + k + l odd, and no such reflection survives for a declared bcc phase | implemented | `CompositeSAEDPattern.centering_audit()` / `phase_centering_is_declared(...)`. Closes a silent failure mode: an undeclared body-centred phase was simulated as primitive and listed forbidden reflections. |
| Gnomonic projection | Closed-form identities: a direction at angle $\psi$ from the detector normal projects to radius exactly $\tan\psi$ (checked at 0, 15, 30, 45 and 60 degrees); direction/pixel round trips exact to 1e-12; a backward direction is flagged invalid rather than mirrored; the pattern centre maps to the gnomonic origin and to `pattern_center_px` | implemented | `GnomonicProjection`. The tangent identity pins the projection scale without reference to any crystallography. Worked example `diffraction-gnomonic-zone-axis-radius` in the diffraction gallery. |
| Kikuchi band geometry | The defining projection property — every band centre trace satisfies its own line equation $ax + by + c = 0$ to 1e-14 relative — checked at three detector tilts including 25 degrees; both edges lie on their Kossel cones ($\hat r \cdot \hat n = \pm\sin\theta_B$) to 1e-12; the analytic apparent width agrees with a direct numerical measurement along the perpendicular through the pattern centre to 1e-3 relative | implemented | `KikuchiBand`, `simulate_kikuchi_pattern`. Edges are sampled on the exact cones, so they are conics; a dedicated test asserts an edge is **not** a straight line, which would fail for a small-angle-linearized implementation. |
| Kikuchi band width against literature | Bragg's law evaluated by hand from the cell: Ni $d_{111} = 3.52387/\sqrt{3} = 2.034510$ Å with the standard 20 kV relativistic wavelength 0.085883 Å gives a band width $2\theta_B = 2.4187$ degrees, the familiar ~2.4 degree width of the strongest nickel bands | implemented | Worked example `diffraction-ni-111-kikuchi-band-width`. Also pinned: higher beam energy narrows every band, and band width orders strictly with $d$-spacing. |
| Electron structure factors on an absolute scale (CBED) | The Mott-Bethe identity itself: PyTex stores X-ray form factors as $Z - 41.78214\,s^{2}\sum a_i e^{-b_i s^{2}}$ and $41.78214 = 8\pi^{2}a_0$, so $f_e = (Z - f_x)/(8\pi^{2}a_0 s^{2})$ must return exactly $\sum a_i e^{-b_i s^{2}}$ — asserted to 1e-12 relative for Al, Ni and Zr. The relativistic factor is pinned structurally: the ratio of $\lvert F_g\rvert$ at 300 kV and 100 kV must equal the ratio of $1 + E/m_0c^2$ | implemented | `pytex.diffraction.scattering.electron_scattering_factors`, `pytex.diffraction.cbed.electron_structure_factor_angstrom`. This is the quantity whose scale is invisible in the geometry: a wrong prefactor produces perfectly plausible fringes at the wrong spacing, so both ingredients are asserted rather than reviewed. |
| Extinction distances against published values | Aluminium at 100 kV: $\xi_{111} = 555$ against the tabulated 556, $\xi_{200} = 664$ against 673, $\xi_{220} = 1063$ against 1057 — within 1.4 percent throughout. Aluminium is the calibration case because the fitted scattering-factor parametrization is most accurate for light elements | implemented | `extinction_distance_angstrom`; baseline Williams and Carter, *Transmission Electron Microscopy*, 2nd ed., Table 23.1. For nickel the same calculation runs about 11 percent high, which is stated in the docstring rather than hidden, and is why the thickness fit measures $\xi_g$ instead of taking it from a table. Worked example `diffraction-cbed-aluminium-extinction-distances-at-100kv`. |
| Two-beam rocking curve | Closed-form identities: $I_g(0) = \sin^{2}(\pi t/\xi_g)$ exactly, giving full transfer at $t = \xi_g/2$ and full return at $t = \xi_g$; intensity bounded in $[0, 1]$; a forbidden reflection ($\xi_g = \infty$) diffracts nothing; minima at $t\,s_{\mathrm{eff}} = n$ recovered to 2e-6 in $s$ from a dense sampling | implemented | `two_beam_rocking_curve`. Howie-Whelan without absorption; the transmitted disc is the exact complement $1 - I_g$, asserted pointwise across a simulated disc. |
| CBED disc geometry and regime | $R_{\mathrm{disc}} = (L\lambda)\,\alpha/\lambda = L\alpha$, so the wavelength cancels; the excitation error is exactly linear along $\mathbf{g}_\perp$ and exactly constant across it (second differences vanish to 1e-12), which is why the fringes are straight and perpendicular to $\mathbf{g}$; the Kossel-Moellenstedt threshold is crossed exactly where $2\alpha/\lambda$ reaches the nearest disc separation | implemented | `simulate_cbed_pattern`, `CBEDPattern.is_kossel_moellenstedt`. With `method="two-beam"` each disc is an independent calculation: geometry, regime and fringe positions are meaningful, relative disc intensities are not, and `describe()` says so on every pattern. `method="bloch"` makes the discs mutually consistent; see the dynamical rows below. |
| Foil thickness from CBED fringes | Analytic inversion: fringe positions generated from $s_n = \sqrt{(n/t)^2 - \xi_g^{-2}}$ for $t = 2000$ Å and $\xi_g = 500$ Å are recovered to 1e-6 Å by the Kelly $(s_n/n)^2$ against $1/n^2$ fit. End-to-end through the public simulation path: Ni (200) at 1500 and 2000 Å and Zr $(10\bar{1}0)$ at 2000 and 3000 Å, all in the Kossel-Moellenstedt regime, recover $t$ and $\xi_g$ to better than 0.1 percent | implemented | `thickness_from_fringe_minima`, `fringe_minimum_excitation_errors`. Both unknowns come from one fit, so the thickness does not inherit a tabulated $\xi_g$. Failure modes pinned: a wrong first-order assignment tilts the line and implies a negative $1/\xi_g^{2}$, so the routine raises instead of returning a plausible number; minima that crowd rather than spread are rejected for every assignment. Worked example `diffraction-cbed-two-beam-thickness-inverts-the-fringe-relation`. |
| HOLZ ring radii | $G_n \simeq \sqrt{2nH/\lambda}$ with $H = 1/\lvert\mathbf{r}_{uvw}\rvert$ exact; inverting the computed radius recovers Ni $a$ down $[001]$, $a\sqrt{3}$ down $[111]$, Zr $c$ down $[0001]$ and Zr $a$ down $[11\bar{2}0]$ to the printed precision. Layers with no allowed reflection are omitted rather than reported | implemented | `holz_ring_radii_inv_angstrom`. The zirconium $c$ case is the point: no $[0001]$ zone-axis spot pattern carries $c$ at all. The small-angle approximation is in the radius only; the layer spacing itself is exact. |
| Many-beam Bloch-wave coupling | The solver's own limiting case, which is the only standard available: restricted to two beams it must reproduce the Howie-Whelan closed form $\sin^{2}(\pi t s_{\mathrm{eff}})/(\xi_g s_{\mathrm{eff}})^{2}$, asserted to 2e-15 over 401 excitation errors. That single check pins the diagonal convention $2s_g$, the off-diagonal scale $\lvert\nu_g\rvert = 1/\xi_g$ and the factor $i\pi$ simultaneously. Unitarity is the global check: without absorption $\mathbf{A}$ is Hermitian, so $\sum_g I_g = 1$ to 1e-12 at every tilt and thickness | implemented | `pytex.diffraction.dynamical.solve_bloch_waves`. The absolute scale is inherited from the extinction distance already validated against Williams and Carter Table 23.1, not re-asserted. Unitarity is what catches obtaining the Bloch-wave excitation amplitudes by projection, which the non-orthogonal eigenvectors do not permit. Worked examples `diffraction-dynamical-two-beam-limit-of-the-many-beam-solver` and `diffraction-dynamical-intensity-is-conserved-without-absorption`. |
| Absorption (imaginary optical potential) | Structural theorems rather than magnitudes: normal absorption sits on every diagonal element and must therefore factor out exactly as $e^{-2\pi t/\xi'_0}$ (asserted to 1e-10 by dividing it out and recovering the absorption-free result); and the Hashimoto-Howie-Whelan result, that anomalous absorption makes the bright-field rocking curve asymmetric in $s$ (>0.8 relative) while the dark-field one stays symmetric (<1e-10) | foundational | `pytex.diffraction.dynamical.AbsorptionModel`. The *structure* is exact and the observable consequences are derived from the eigenvector structure; the *magnitudes* are the customary phenomenological ratios of Hirsch et al. Absorptive form factors (Hall-Hirsch Einstein model, Bird-King parametrization) are not computed, and `describe()` says so, so no quantitative absorption strength is claimed. |
| HOLZ line geometry and metrology | Cross-module: points on a computed line must have $s_g = 0$ according to `pytex.diffraction.dynamical`, which derives the excitation error independently — asserted to 1e-15. The strain/wavelength degeneracy is an exact algebraic cancellation, asserted to 1e-16 across every line for strains from 1e-4 to 2e-2; the analytic strain sensitivity is checked against central differences of the closed form | implemented | `pytex.diffraction.holz.holz_line_pattern`. Positions are exact to the accuracy of $s_g$; contrast is not modelled and the object says so. Worked example `diffraction-holz-strain-and-wavelength-are-exactly-degenerate`. |
| Diffraction groups and point-group determination | The published count and membership: the construction must yield exactly Buxton's 31 diffraction groups from PyTex's own operator tables, checked symbol by symbol. Canonical entries checked against the literature (`m-3m [001]` gives `4mm1_R`; `-43m [001]` gives `4_Rmm_R` with bright field 4mm over whole pattern 2mm; `-6m2 [001]` gives `3m1_R` with a six-fold bright field over a 3m pattern). The centrosymmetry correspondence is asserted exhaustively over all 32 point groups at every characteristic beam direction | implemented | `pytex.diffraction.diffraction_groups`. Derived rather than transcribed, so the point-group table follows by inversion and the count is a result. End to end from a simulated pattern, zincblende and diamond down [001] are separated by whole-pattern symmetry with residuals of 0.00 against 0.32. Worked examples `diffraction-groups-construction-yields-buxtons-thirty-one`, `diffraction-groups-friedel-observation-splits-the-point-groups`, `diffraction-groups-zincblende-down-001-loses-the-two-fold`. |
| CBED dynamical breadth | — | planned | Still absent, and stated on every pattern: Bethe perturbation of weak beams (so a full HOLZ ring costs $O(mn^3)$), computed absorptive form factors, Buxton's dark-field and $\pm\mathbf{G}$ observations for reflections on symmetry lines, and specimen realism (wedge, bending, strain gradient, probe aberration, inelastic background). No parity with a dynamical code such as JEMS is claimed. |
| Kikuchi zone axes and frame chain | Every reported zone axis lies on the centre line of each band whose plane satisfies the zone law, to 1e-9, and the reported band count equals the number of such bands; the closed-form anchor is that $[011]$ of a cubic phase at the cube orientation with an untilted detector projects to gnomonic radius exactly 1 | implemented | The radius identity pins the whole crystal → specimen → laboratory → detector chain: a transposed or misordered rotation anywhere along it moves the value. |
| Kikuchi band intensities | — | planned | Kinematic $\lvert F\rvert^2$ proxy only. The excess/deficiency asymmetry across a band is dynamical and is **not** modelled, so simulated bands are symmetric; higher-order Laue zone rings, background, and detector point-spread are also absent. Band *positions* — which orientation determination uses — are unaffected. |
| March-Dollase preferred orientation | The exact spherical normalization $\frac{1}{2}\int_{-1}^{1}(Au^2+B)^{-3/2}du = 1$ for every $r$, checked by equal-area quadrature at five coefficients; the closed-form limits $P(0)=r^{-3}$ and $P(\pi/2)=r^{3/2}$ to 1e-12; a family-averaged cubic {111} factor under a (111) axis at $r=1/2$ equal to $2 + 162/(65\sqrt{65})$ to 1e-12, derived by hand | implemented | `MarchDollaseModel`. The March function returns exactly 1 at $r=1$, so "no preferred orientation" leaves intensities bit-identical. Family averaging is pinned by requiring every representative of a family to receive the same factor. Two worked examples in the diffraction gallery. |
| ODF-weighted preferred orientation | The random-texture identity: a uniform ODF gives a factor of 1 for every reflection (measured 0.9999). A fibre planted about ND by the canonical constructors enhances the pole that was planted, not another | implemented | `ODFPreferredOrientationModel` — the texture core driving powder intensities, with no fitted parameter. The kernel response is divided by its spherical mean, computed by Gauss-Legendre quadrature, which is what makes the factors multiples of random. Worked example in the diffraction gallery. |
| Preferred-orientation application contract | Applying a correction changes intensity and nothing else: indices, d-spacing, $2\theta$, multiplicity and structure factor are all preserved, and the $2\theta$ grid is unchanged; the K-alpha2 line receives the same correction, so the doublet ratio does not depend on texture | implemented | `apply_preferred_orientation`, and `generate_xrd_pattern(preferred_orientation=...)` which returns the *corrected* reflection list so pattern and list cannot disagree. Corrected lists are deliberately not renormalized: the ratios carry the texture. |
| Absorption, extinction, surface roughness | — | planned | These also alter powder intensities and are not modelled, so a preferred-orientation correction alone does not make intensities quantitative. |
| External package or literature parity | Pinned `pymatgen` XRD and `diffsims` SAED reference artifacts | foundational | Compact cubic and HCP external-baseline cases are pinned in-repo, but broader low-symmetry material and orientation coverage remains ahead. Kikuchi geometry is currently validated against closed-form identities and hand-derived Bragg values rather than against an external simulator such as EMsoft or kikuchipy. |

## Current Posture

The diffraction layer is scientifically meaningful, internally tested, and backed by real
external-baseline artifacts. The strongest current claim is geometric and shell-structure agreement
for the pinned starter cases, not full physical parity across intensity models or material space.

In practical terms:

- peak-position and multiplicity agreement are the hard powder-XRD claims
- shell geometry and family coverage are the hard SAED claims
- intensity differences remain informative rather than normative

## Evidence Hardening Queue

Before stronger diffraction claims are made, the next validation pass should add:

- additional open material fixtures beyond the new HCP starter case that exercise lower symmetry
  and overlapping multi-family reflection behavior
- separate ledgers for geometric agreement, shell/family agreement, and intensity-model limitations
- pinned external-baseline regeneration metadata for each new `pymatgen` or `diffsims` comparison
  artifact
